Foundations of SBI > Bayesian inference

The inverse problem — formally

Bayesian inference provides a rule for updating our prior knowledge about parameter $\theta$ given new data $x$.

\[ p(\boldsymbol\theta \mid \mathbf{x}) \;=\; \frac{p(\mathbf{x}\mid\boldsymbol\theta)\, p(\boldsymbol\theta)}{p(\mathbf{x})} \]
  • Prior \(p(\boldsymbol\theta)\): what we believed before seeing data.
  • Likelihood \(p(\mathbf{x}\mid\boldsymbol\theta)\): what the physics model predicts.
  • Posterior \(p(\boldsymbol\theta\mid\mathbf{x})\): what we want.
  • Evidence / Marginal likelihood \(p(\mathbf{x}) = \int p(\mathbf{x}\mid\boldsymbol\theta)\, p(\boldsymbol\theta)\, d\boldsymbol\theta\).

Note. SBI only requires samples from \(p(\mathbf{x}\mid\boldsymbol\theta)\) — i.e. a running simulator. Likelihood-based methods (MCMC, HMC, VI) need pointwise evaluations of \(p(\mathbf{x}\mid\boldsymbol\theta)\), which are often unavailable when detector effects or systematics must be marginalised (= integrated) out.

Foundations of SBI > Neural networks

What is a neural network?

Two views of one object: a computation, and a graph. The weights in the formulas are the connections.

1 · As a computation

\( \mathbf{h}_1 = \varphi(W_1\,\mathbf{x} + \mathbf{b}_1) \)
\( \mathbf{h}_2 = \varphi(W_2\,\mathbf{h}_1 + \mathbf{b}_2) \)
\( \mathbf{h}_3 = \varphi(W_3\,\mathbf{h}_2 + \mathbf{b}_3) \)
\( \mathbf{y} = W_4\,\mathbf{h}_3 + \mathbf{b}_4 \)

A stack of affine maps \(W\mathbf{h}+\mathbf{b}\) interleaved with a simple nonlinearity \(\varphi\), e.g. \(\varphi(\cdot)=\max(0,\cdot)\). Nothing more: matrix multiplies and a squashing function. The numbers in \(W,\mathbf{b}\) are learned.

2 · As a network

Each node is a unit applying \(\varphi\); each edge carries one weight \(W_{ij}\). The matrices on the left are exactly these connections, drawn out. Layers = the columns; depth = how many.

Foundations of SBI > Neural networks

One concept, many architectures

The recipe never changes: a stack of learned affine maps and nonlinearities, fitted by gradient descent. What changes is the wiring — the structure built in to match the data and the mapping you want to learn (the inductive bias).

MLP fully connected
vector → vector
No structure assumed — every input talks to every unit. The general-purpose baseline (our adder above). Flexible, but blind to geometry or order.
CNN convolutional
image → label / value
Shared local filters + translation invariance. Built for data on a grid: images, spectrograms, sky maps.
U-Net encoder–decoder
image → image
Down- then up-sampling with skip connections. Dense field-to-field maps: denoising, segmentation, simulation emulation.
Graph NN message passing
graph → graph / value
Operates on nodes and edges with permutation symmetry. Irregular structure: particle clouds, molecules, halos, meshes.
Transformer attention
set / sequence → …
Every element attends to every other, weighted by learned relevance. Long-range relations: language, time series, sets of detections.

Same training principle throughout — pick the architecture whose built-in symmetries match your problem.

Foundations of SBI > Rejection ABC

Demo — Rejection ABC

Rank the same cloud against \(x_\mathrm{obs}\), keep the closest, read off the posterior

Amortised: moving \(x_\mathrm{obs}\) does not re-run the simulator — the same cloud is just re-ranked. Simulation cost is paid once; every new observation is then essentially free.

Foundations of SBI > Rejection ABC

Key takeaways

Generic properties and challenges with this approach.

Works generically (and keeps working)

  • Amortised inference. Pay the simulation cost once; any new observation \(x_\mathrm{obs}\) is then a free query.
  • No likelihood evaluations. Only simulator samples are needed, never a pointwise \(p(x\mid\theta)\) evaluation.
  • Trivial marginalisation. Nuisances (here the muzzle speed \(v\)) fold in for free by sampling them inside the simulator.

Stays hard (what modern SBI is about)

  • The \(\varepsilon \to 0\) limit. Sharper posteriors need a tighter acceptance band, which needs exponentially more simulations. This is the sample-efficiency cliff.
  • Density estimation in high D. Our demo was 1-dimensional; with many parameters histogram looses meaning and smoothing becomes hard.
  • Summary construction. We only had one observable, for higher dimensional data we need sufficient data summaries. Hand-picked summaries do not scale to images, waveforms or graphs.

Foundations of SBI > Flow matching

The hard part: representing a probability density

A prior, a likelihood, a posterior, an evidence — all of statistics is a statement about distributions.

We need to approximate probability distributions, \( q_\phi(\theta \mid x) \approx p(\theta \mid x) \), given only samples from a simulator — far more constrained objects than the functions of Part 1.

What a density must satisfy

Non-negative, \(q_\phi(\theta)\ge 0\).
Easy — exponentiate.

Normalized, \(\int q_\phi(\theta)\,d\theta = 1\).
Hard. This is a global constraint: change the network anywhere and the integral changes everywhere.

And two operations, both fast

Evaluate — given \(\theta\), return \(q_\phi(\theta)\).
Importance weights, likelihoods, model comparison.

Sample — draw fresh \(\theta \sim q_\phi\).
Error bars, corner plots, propagating uncertainty.

Both get called millions of times in a real analysis, so “fast” is part of the specification, not a nicety. No classical representation gives you all of this at once.

Foundations of SBI > Flow matching

Flow matching in three equations

Start from a unit Gaussian and move the points until they are distributed like \(p\).

The motion is a velocity field \(v_\phi(\theta,t)\) — a simple MLP, taking a position \(\theta\) and a time \(t\in[0,1]\). Write \(\theta_0\sim\mathcal N(0,I)\) for a noise point and \(\theta_1\sim p\) for a data point.

1. Train. Sit on the straight line between a random pair and regress the velocity onto its direction:

\[ \mathcal L(\phi) = \mathbb E_{t,\theta_0,\theta_1}\Big[\;\big\|\,v_\phi\big( \underbrace{(1-t)\theta_0 + t\,\theta_1}_{\textstyle \theta_t},\,t\big) - (\theta_1-\theta_0)\,\big\|^2\Big],\quad t\sim U(0,1) \]

2. Sample. Integrate the learned field from noise to data:

\[ \theta(0)=\theta_0\sim\mathcal N(0,I),\qquad \frac{d\theta}{dt}=v_\phi\big(\theta(t),t\big),\qquad \theta(1)\sim q_\phi \approx p \]

3. Evaluate. Integrate backwards, accumulating the divergence:

\[ \log q_\phi(\theta_1) = \log \mathcal N\big(\theta(0);0,I\big) - \int_0^1 \nabla\!\cdot v_\phi\big(\theta(t),t\big)\,dt \]

Lipman et al. 2022, arXiv:2210.02747 · Liu et al. 2022, arXiv:2209.03003 · Albergo & Vanden-Eijnden 2022, arXiv:2209.15571 · for GW posteriors: Dax et al. 2023, arXiv:2305.17161

Foundations of SBI > Flow matching

Aside: why random pairs give the right field

Straight lines cross, so no single pair defines the motion. Least squares averages them — and that average is exactly right.

To prove. With \(p_t=\mathrm{Law}(\theta_t)\), the field must satisfy the continuity equation — then the ODE's marginals are \(p_t\), and \(\theta(1)\sim p_1=p\):

\[ \partial_t p_t + \nabla\!\cdot\!\big(p_t\,v^\star\big) = 0 , \qquad v^\star(x,t)=\mathbb E\big[\theta_1-\theta_0 \,\big|\, \theta_t=x\big] \]

Proof. For any test function \(\varphi\):

\[ \begin{aligned} \int \varphi\,\partial_t p_t \,dx &= \frac{d}{dt}\,\mathbb E\big[\varphi(\theta_t)\big] = \mathbb E\big[\nabla\varphi(\theta_t)\cdot(\theta_1-\theta_0)\big] \;\overset{\text{tower}}{=}\; \mathbb E\big[\nabla\varphi(\theta_t)\cdot v^\star(\theta_t,t)\big] \\[2pt] &= \int \nabla\varphi\cdot v^\star\,p_t\,dx \;\overset{\text{by parts}}{=}\; -\int \varphi\,\nabla\!\cdot\!\big(p_t v^\star\big)\,dx \qquad\blacksquare \end{aligned} \]
Where each step comes from
  • \(\theta_t\) is affine in \(t\), so \(\dot\theta_t=\theta_1-\theta_0\)
  • \(\nabla\varphi(\theta_t)\) depends only on \(\theta_t\) → swap the arrow for its conditional mean
  • \(\varphi\) arbitrary → the equation holds pointwise
What this does not say
  • The trajectories are not the straight lines — those cross, ODE paths cannot
  • The pairing is destroyed; only \(p_t\) survives, so the coupling need not be optimal
  • Endpoints are free: \(p_0=\mathcal N(0,I)\), \(p_1=p\) by construction

Foundations of SBI > Flow matching

Aside: no network is being trained in that demo

The optimal velocity field for a finite sample set is known in closed form.

Take the straight-line interpolant and a target that is just a bag of points \(\{\theta_1^j\}\). At time \(t\), the paths starting from \(\mathcal N(0,I)\) put a Gaussian of width \((1-t)\) around each \(t\,\theta_1^j\), so the marginal is a mixture,

\[ p_t(\theta) = \frac1N \sum_j \mathcal N\big(\theta;\, t\,\theta_1^j,\, (1-t)^2 I\big). \]

Given \(\theta\) and a specific endpoint \(\theta_1^j\), the noise point is pinned: \(\theta_0 = (\theta - t\,\theta_1^j)/(1-t)\), so that pair's arrow is \((\theta_1^j - \theta)/(1-t)\). The loss minimiser is the average arrow, weighted by how plausible each endpoint is:

\[ v^\star(\theta,t) = \sum_j w_j \, \frac{\theta_1^j - \theta}{1-t}, \] \[ w_j \propto \mathcal N\big(\theta;\, t\,\theta_1^j,\, (1-t)^2 I\big) \]

That is what the browser evaluates — 420 particles against 420 target points, every frame. So the animation is not an approximation of flow matching: it is the field a perfectly trained network would converge to.

Foundations of SBI > Flow matching

Conditional flow matching = amortized posterior estimation

One extra input to the velocity field, and a generative model becomes an inference engine.

We rarely want one distribution — we want a family indexed by an input. Feed the condition to the field alongside \(\theta\) and \(t\):

\[ \mathcal L(\phi) = \mathbb E_{t,\,\theta_0,\,(\theta,x)}\Big[\;\big\|\, v_\phi\big((1-t)\theta_0 + t\,\theta,\;t \,\big|\, \color{#2980b9}{x}\big) - (\theta-\theta_0)\,\big\|^2\Big] \]

with the pairs drawn jointly from the simulator, \((\theta,x)\sim p(\theta)\,p(x\mid\theta)\): each training \(\theta\) comes with the \(x\) it produced.

The minimiser of this loss is the posterior. \( q_\phi(\theta\mid x) \to p(\theta\mid x) \) — no likelihood was ever written down, only simulated. This is Neural Posterior Estimation, with flow matching as the density estimator.

And because the network learned the whole family at once, a new observation \(x_{\rm o}\) it has never seen costs one ODE solve, not a new training run: that is amortization, and it is the entire reason this machinery is interesting for GW astronomy.

Implicit: Towards a realistic analysis of the SGWB

During the training, the simulator can include any effect we like (e.g. a transient contaminant), and SBI will marginalise over it at inference time. Neglecting it instead leads to biased results.

Power-law (with stochastic transient)
  • In absence of transients, MCMC results are recovered with the same precision
  • In the presence of transients, MCMC is biased when they are neglected (necessary for a tractable likelihood), while Saqqara / Swyft correctly marginalises over them (if present in the simulation data)

Applications > Native capabilities of SBI

Marginal: Joined analysis of overlapping GW signals

Instead of training the full posterior $q_\phi(\mathbf{z}_1, \mathbf{z}_2 \mid \mathbf{x})$, we can train a marginal posterior $q_\phi(\mathbf{z}_1 \mid \mathbf{x})$ for the parameters of interest $\mathbf{z}_1$, while marginalising over the nuisance parameters $\mathbf{z}_2$ (e.g. the second overlapping signal), and vice versa.

Applications > Underexplored capabilities of SBI

Sequential SBI — focusing simulations round by round

We want the posterior \(p(\theta\mid x_o)\) for a single target observation \(x_o\) (right, fixed). Simulating across the whole prior wastes most of the budget on \(\theta\) that could never produce \(x_o\).

The loop:

  1. Simulate. Draw \(\theta\) from the current proposal, run the simulator to get \(x\) (top training panel flickers through fresh realisations).
  2. Learn. Fit the posterior on \((\theta,x)\) pairs — the ellipse is the new estimate given this round's points.
  3. Focus. Use that ellipse as the next proposal, so the next round only simulates where it matters.

Each round the cloud tightens around the truth and the simulated rings start to resemble the target. A few rounds buy the accuracy a fixed budget could never reach.
